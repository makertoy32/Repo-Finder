# GitHub Random Repository Finder

A responsive GitHub Random Repository Finder built with React and the GitHub API. Select a programming language and get a random repository matching that language.

## Features

- 🔎 Search and select programming languages
- 🎲 Fetch a random GitHub repository
- ⭐ Display repository stars
- 🍴 Display repository forks
- 🐛 Display open issues
- 📝 Display repository description
- 🔄 Refresh to get another random repository
- ⏳ Loading state
- ❌ Error state
- 📭 Empty state
- 📱 Responsive design
- ✨ Smooth animations with Motion

## Technologies Used

- React
- JavaScript
- Tailwind CSS
- Motion
- GitHub Repository Search API
- Vite
